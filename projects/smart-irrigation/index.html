Smart Irrigation System (ESP32 + Arduino IoT Cloud)

An irrigation automation project that aims to improve crop yields and water management for smallholder farmers, roof gardens and flower tubs. Soil-moisture and water-level sensors feed an ESP32, which decides how much water the plants get and can be monitored and controlled through Arduino IoT Cloud.

Type
Irrigation automation
Platform
ESP32 + Arduino IoT Cloud
Users
Smallholder farmers, roof gardens, home gardeners
Connectivity
Wi-Fi, with offline operation
  • ESP32
  • Arduino IoT Cloud
  • Wi-Fi
  • Soil-moisture sensor
  • Water-level sensor
  • Actuators
  • Web & mobile dashboard

How it works

  1. Sense: soil-moisture sensors and water-level sensors collect field data.
  2. Decide: the data goes to the ESP32 gateway unit, which runs an algorithm with threshold values for soil moisture and water level to optimise water use for the crops.
  3. Act: the ESP32 triggers the actuators that control the quantity of water delivered.
  4. Monitor: over Wi-Fi, the system can be monitored and controlled from Arduino IoT Cloud web and mobile applications.

Key features

  • Threshold-based watering: irrigation follows soil moisture and the available water level.
  • Remote control: web and mobile dashboards through Arduino IoT Cloud.
  • Works offline: the controller keeps operating without cloud communication.
  • Low power: designed to maximise results while using less power.

Impact

The project aims to deliver a positive economic return for farmers and their families by improving yields and promoting sustainable water management.
