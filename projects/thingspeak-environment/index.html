Environment Monitoring & Visualization with ThingSpeak

A multi-sensor station that monitors air and water quality, soil moisture, temperature and wind flow, and sends every reading to the ThingSpeak cloud for storage and visualization, building a dataset for environmental research.

Type
Environmental monitoring
Platform
Arduino Uno + ESP-01 (Wi-Fi)
Cloud
ThingSpeak
Purpose
Data collection for environmental research
  • Arduino Uno
  • ESP-01
  • Wi-Fi
  • ThingSpeak
  • pH sensor
  • Air-quality sensor
  • Soil-moisture sensor
  • Temperature sensor
  • Wind-flow sensor

How it works

An Arduino Uno reads the sensors, and an ESP-01 Wi-Fi module handles internet communication. All collected data is pushed to the ThingSpeak server, where it is stored and charted so it can be reviewed and analysed later.

Parameters monitored

  • pH (water quality)
  • Air quality
  • Soil moisture
  • Temperature
  • Wind flow
