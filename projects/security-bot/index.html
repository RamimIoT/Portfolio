IoT Security Bot: ESP32-CAM + Telegram with OTA

A simple, affordable surveillance device: when a PIR sensor detects motion, an ESP32-CAM takes a picture and sends it to a chosen Telegram account or group. The same Telegram chat is used to control the device, and the firmware updates over the air.

Type
Motion-triggered photo surveillance
Platform
ESP32-CAM with PIR sensor
Interface
Telegram bot
Power
3.7 V battery with power-management circuit
  • ESP32-CAM
  • PIR motion sensor
  • Telegram Bot
  • OTA firmware updates
  • 3.7 V battery
  • Power-management circuit

Overview

The goal was a simple, affordable security system built with IoT technology. A small battery-powered ESP32-CAM unit watches an area, photographs any movement and delivers the pictures to Telegram, the same app used to control the device.

How it works

  1. The PIR sensor detects motion.
  2. The ESP32-CAM takes a picture.
  3. The picture is sent to a specific Telegram account or group.

Control from Telegram

  • Picture interval: set the time interval for sending pictures.
  • Flashlight: turn the ESP32-CAM's flash on or off.
  • Device status: check the state of the security bot from the Telegram app.
  • OTA updates: firmware is updated wirelessly, over the air.

Hardware

  • ESP32-CAM
  • PIR motion sensor
  • 3.7 V battery with a power-management circuit
