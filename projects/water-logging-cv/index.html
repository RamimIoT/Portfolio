Water Logging Monitoring with Computer Vision & IoT

A real-time monitoring and alert system that combines IoT sensors with a cloud server running a pre-trained YOLOv4 model to detect water logging as it happens, and alerts the system owner by e-mail.

Overview

The system is built for organisations and individuals concerned with environmental monitoring who need to know about water logging the moment it happens. IoT sensors gather data on site, a cloud server analyses it with a pre-trained YOLOv4 computer-vision model, and the owner is alerted straight away.

How it works

  • Sensing: various IoT sensors collect data from the monitored area.
  • Detection: a cloud server runs a pre-trained YOLOv4 model to detect water logging in real time.
  • Alerts: e-mail notifications go to the system owner as soon as water logging is detected.
  • Monitoring: the situation can be followed through cloud-based monitoring.
